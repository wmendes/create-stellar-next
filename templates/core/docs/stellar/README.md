# Stellar guides for this project

These guides match the versions this project was generated with. Read the one for the area you are
changing before you change it.

{{DOCS}}

Examples use `npm run`. With another package manager, use its own form, such as `pnpm setup`.

For the Stellar CLI's own guide for agents, run `stellar skill`. Check `stellar <command> --help`
before using a flag. Configuration is in `.env`; `.env.example` lists every key.
